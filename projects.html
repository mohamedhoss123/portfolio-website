VidFlow

Microservices-based video streaming platform

A high-performance streaming platform built on a distributed microservices architecture to handle resource-intensive media processing. NestJS owns the business logic, while a dedicated Go service handles transcoding and talks to the gateway over gRPC.

What I built

  • Achieved 100% non-blocking API responses by moving heavy transcoding into background workers.
  • Reduced transcoding latency with BullMQ + Redis, delivering 1080p, 720p and 480p outputs asynchronously.
  • Enabled type-safe, high-throughput service calls by implementing gRPC between NestJS and Go.
  • Shipped a streaming UI with discovery, subscriptions and real-time engagement metrics.

// scheduling

GU Halls

Resource optimisation & scheduling system

An infrastructure management platform that eliminates resource underutilisation and automates academic scheduling. Constraint programming turns complex academic requirements into optimised, conflict-free timetables.

What I built

  • Generated conflict-free timetables with Google OR-Tools, respecting instructor availability, hall capacities and workloads.
  • Cut inter-lecture transition time by an estimated 20% with a distance-aware allocation algorithm.
  • Improved throughput by 60%+ by decoupling scheduling via RabbitMQ workers.
  • Built real-time utilisation dashboards with Express.js and PostgreSQL.
  • Added load-balancing logic across halls, labs and classrooms.
